# Meeting Scheduler

A small web app for scheduling candidate interview meetings: create, list,
edit and delete meetings.

The requirements are in [docs/requirements.md](docs/requirements.md).

## Status

Work in progress. The repository holds the Next.js app as generated by
`create-next-app`; the API comes next.

## Layout

| Path | What |
| --- | --- |
| `web/` | Frontend: Next.js (App Router), TypeScript |
| `docs/` | Requirements |

## Run locally

Needs Node.js 26 (see `.nvmrc`) and pnpm.

```bash
pnpm install
pnpm --filter web dev   # http://localhost:3000
```

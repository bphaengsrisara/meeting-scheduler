# Meeting Scheduler

A small web app for scheduling candidate interview meetings: create, list,
edit and delete meetings.

The requirements are in [docs/requirements.md](docs/requirements.md).

## Status

Work in progress. The web app is still the page generated by
`create-next-app`. The API has its structure, configuration, logging and
tests in place, and one route, `GET /health`.

## Layout

| Path    | What                                                    |
| ------- | ------------------------------------------------------- |
| `web/`  | Frontend: Next.js (App Router), TypeScript              |
| `api/`  | Backend: Express 5, TypeScript, run directly by Node.js |
| `docs/` | Requirements                                            |

The two apps share one pnpm workspace. The database will be PostgreSQL.

## Run locally

Needs Node.js 26 (see `.nvmrc`) and pnpm.

```bash
pnpm install
pnpm --filter web dev   # http://localhost:3000
pnpm --filter api dev   # http://localhost:3001/health
```

The API reads `api/.env` if it exists; `api/.env.example` lists the
variables and their defaults. They are checked at startup, and the API
stops with a clear message if one is invalid.

## API structure

| Path                | What                                               |
| ------------------- | -------------------------------------------------- |
| `src/index.ts`      | Starts the server                                  |
| `src/app.ts`        | Builds the Express app (used by the tests as well) |
| `src/env.ts`        | Checks the environment variables with Zod          |
| `src/lib/logger.ts` | Logger (pino); logs every request                  |
| `src/middleware/`   | The 404 and error handlers, one JSON error shape   |
| `src/health.ts`     | `GET /health`                                      |

## Check the code

Run from the repository root:

```bash
pnpm lint        # Prettier check, then ESLint in api and web
pnpm lint:fix    # ESLint --fix in api and web, then Prettier rewrite (last, so lint passes)
pnpm typecheck   # TypeScript check in api
pnpm test        # Unit tests with Vitest in api
```

Prettier has one config for both apps, `.prettierrc.json` at the root. A
formatting problem makes `pnpm lint` fail; `pnpm lint:fix` fixes it. Each
root script names the apps it runs in, so an app that is missing the script
makes the command fail instead of being skipped. The API's ESLint config
adds typescript-eslint's strict rules and SonarJS.
